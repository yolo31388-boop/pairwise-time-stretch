# pairwise-time-stretch

把一段采访变速后声音像被掐住脖子：相位声码器窗长固定，低频段周期被破坏；变速只改播放速率，采样率没跟着改，音调一起升高；瞬态段被相位抹平，鼓点变成糊；分块处理时块边界相位不连续，出现周期性咔哒；实时变速的延迟没有算进总预算，口型和声音对不上；多轨对齐只用帧号，变速后各轨长度不同；采样率切换后窗函数没重算，高频出现镜像；共振峰跟着音调一起移，听起来像另一个人；丢帧时直接跳采样，波形断裂；不同段落用不同速率，拼接处能量突变。audio/time_stretch.py 是核心，tests/test_time_stretch.py 15 个红。要修的是：自适应窗长；保持音调；瞬态保护；块边界相位；延迟预算；多轨时长对齐；采样率重建；共振峰保持；丢帧平滑；分段能量归一。

## 运行

```bash
python -m pytest tests -q
```
